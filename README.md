Monther Al-Shobaki CV Website
Arabic personal CV website for Monther Tawfeeq Ahmad Al-Shobaki, built as a single static HTML page and published with GitHub Pages.

Website
After GitHub Pages is enabled, the website can be accessed at:

https://tawfiqalshoubaki.github.io/Montheralshobaki/

If the main file is still named cv-shoubaki.html, use:

https://tawfiqalshoubaki.github.io/Montheralshobaki/cv-shoubaki.html

Files
index.html - main website file for GitHub Pages.
cv-shoubaki.html - original CV website file.
.gitignore - excludes generated PDF and temporary DOCX extraction files.
Features
Arabic RTL CV layout.
Print/PDF button for a compact one-page CV.
Teacher contact details.
Clickable phone numbers using tel: links.
References section.
Updating The Website
Edit index.html, then commit and push the changes to GitHub.

git add index.html cv-shoubaki.html README.md
git commit -m "Update CV website"
git push
GitHub Pages may take a few minutes to update after pushing.

GitHub Pages Setup
In the GitHub repository:

Open Settings.
Open Pages.
Choose Deploy from a branch.
Select the branch that contains the website files.
Select / root.
Save.
The public site will be served from GitHub Pages.
